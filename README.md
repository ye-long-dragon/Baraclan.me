### Day 4
- Starting to understand it. My node.js is to serve the backend part of my project. My router for the front end uses a React Router which uses App.tsx in ./client to serve the front end. Compared to EJS, React is a lot more harder as you need to ensure that the entire program is in one file. EJS follow a templating style of programming where it is much easier to not only to maintain using modularization, but also to read. React need the entire code to run in one file, so no matter how much you modularize it, it is difficult and often time hard to maintain especially for an admin page. Will find a much easier way to modularize for next project.

### Day 5
Restructured the entire repository into a production-ready MERN architecture with strict TypeScript across both client and server. Rebuilt the backend into a modular `/server` directory featuring serverless-safe MongoDB caching, rate-limited single-admin authentication using bcrypt and JWT cookies, and strict input and image validation. Reorganized the frontend by isolating all CRUD operations into reusable custom hooks, decoupling API interactions, and removing legacy dark-mode dependencies. Built a protected Admin Control Center featuring tabbed resource management, automated client-side canvas image compression, and full design system alignment with the portfolio.
